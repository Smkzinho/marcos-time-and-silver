# Marcos Time And Silver

PROJETO: MARCOS JOIAS & RELÓGIOS



Crie um e-commerce profissional, moderno, minimalista e totalmente responsivo para a marca Marcos Joias & Relógios.



O objetivo é desenvolver uma loja virtual com aparência de marca premium, excelente experiência de compra e foco em conversão de vendas.



1. IDENTIDADE VISUAL



Utilize uma identidade visual minimalista, baseada exclusivamente em preto, branco e tons neutros.



Paleta:



- Preto principal: #080808

- Branco: #FFFFFF

- Cinza claro: #F5F5F5

- Cinza secundário: #888888

- Cinza escuro: #222222



Não utilizar dourado, bege ou cores vibrantes.



A identidade deve transmitir:



- Sofisticação.

- Modernidade.

- Personalidade.

- Confiança.

- Elegância.



Utilize tipografia moderna e elegante, com títulos marcantes, espaçamento bem trabalhado e textos de fácil leitura.



Utilize a logo original da Marcos Joias & Relógios que será enviada como arquivo de imagem. Não recrie, distorça ou modifique o símbolo original.



2. CABEÇALHO



Criar um cabeçalho profissional contendo:



- Logo da marca à esquerda.

- Menu de navegação centralizado.

- Ícone de pesquisa.

- Ícone de conta.

- Ícone de carrinho com contador de produtos.



Menu:



- Início

- Relógios

- Smartwatches

- Prata 925

- Aço inoxidável

- Banhados a ouro 18k



O cabeçalho deve ser elegante, compacto e responsivo.



No celular, utilizar menu lateral ou menu hambúrguer.



3. BANNER PRINCIPAL



Criar um banner de destaque grande, com fotografia profissional de relógios e joias.



Texto principal:



"ESTILO QUE MARCA PRESENÇA."



Texto secundário:



"Peças selecionadas para quem valoriza cada detalhe."



Botão:

"CONHEÇA NOSSA COLEÇÃO"



Utilizar fotografia editorial de alta qualidade, composição minimalista e contraste entre preto e branco.



Não utilizar banners genéricos ou excesso de elementos gráficos.



4. CATEGORIAS



Criar uma seção visual com cinco categorias:



1. Relógios analógicos

2. Smartwatches

3. Prata 925

4. Aço inoxidável

5. Banhados a ouro 18k



Cada categoria deve possuir:



- Fotografia própria.

- Nome da categoria.

- Link para visualizar os produtos.



5. PRODUTOS EM DESTAQUE



Criar uma vitrine moderna de produtos com cards contendo:



- Fotografia do produto.

- Nome.

- Preço.

- Preço anterior, quando houver promoção.

- Condição de parcelamento.

- Botão de adicionar ao carrinho.

- Etiqueta de lançamento ou promoção, quando aplicável.



Criar seções:



- Mais vendidos.

- Novidades.

- Ofertas especiais.



Utilizar inicialmente produtos demonstrativos, claramente identificados como exemplos, sem inventar avaliações ou informações comerciais reais.



6. PÁGINA INDIVIDUAL DO PRODUTO



Criar uma página completa para cada produto contendo:



- Galeria de imagens.

- Nome do produto.

- Preço.

- Parcelamento.

- Descrição detalhada.

- Material e características.

- Opções de variação, quando aplicáveis.

- Quantidade.

- Botão de comprar.

- Botão de adicionar ao carrinho.

- Informações de entrega.

- Produtos relacionados.



A página deve priorizar imagens grandes e uma experiência de compra simples.



7. CARRINHO



Criar carrinho funcional com:



- Adição e remoção de produtos.

- Alteração de quantidades.

- Atualização automática dos valores.

- Subtotal.

- Campo para cupom de desconto preparado para integração.

- Botão para finalizar compra.



Persistir o carrinho durante a navegação.



Não simular pagamentos reais. Preparar a estrutura para integração com o checkout oficial da Nuvemshop.



8. DIFERENCIAIS DA MARCA



Criar uma seção institucional com quatro diferenciais:



- Produtos selecionados.

- Compra segura.

- Atendimento personalizado.

- Compromisso com a qualidade.



Não inventar certificados, garantias ou prazos comerciais.



9. INSTAGRAM



Criar uma seção de integração visual com Instagram.



Título:

"ACOMPANHE NOSSA MARCA"



Subtítulo:

"Novidades, lançamentos e inspirações para o seu estilo."



Adicionar espaço para inserir o perfil oficial e fotografias da marca.



10. RODAPÉ



Criar um rodapé completo contendo:



- Logo.

- Breve apresentação da empresa.

- Links de categorias.

- Atendimento.

- Política de privacidade.

- Trocas e devoluções.

- Termos de uso.

- Instagram.

- WhatsApp.

- Formas de pagamento, quando configuradas.



11. EXPERIÊNCIA E RESPONSIVIDADE



O site deve funcionar perfeitamente em:



- Smartphones.

- Tablets.

- Computadores.



Priorizar a experiência mobile, pois grande parte dos clientes chegará pelo Instagram.



Utilizar:



- Animações suaves e discretas.

- Transições elegantes.

- Botões bem definidos.

- Navegação intuitiva.

- Carregamento otimizado.

- Fotografias de alta qualidade.

- Espaçamento consistente.



Evitar:



- Excesso de sombras.

- Bordas arredondadas exageradas.

- Cores desnecessárias.

- Elementos decorativos excessivos.

- Aparência de template genérico.



12. ESTRUTURA TÉCNICA E EDITABILIDADE



Desenvolver o projeto com React, TypeScript e componentes reutilizáveis.



Organizar o código para que seja fácil editar:



- Textos.

- Fotografias.

- Logo.

- Cores.

- Categorias.

- Produtos.

- Preços.

- Banners.

- Informações institucionais.



Manter os produtos em uma estrutura de dados organizada, sem espalhar informações fixas por vários componentes.



Preparar uma camada de integração com a API da Nuvemshop para futuramente sincronizar:



- Produtos.

- Preços.

- Estoque.

- Categorias.

- Carrinho e checkout.



Não expor tokens ou credenciais no frontend. Utilizar backend seguro para integrações.



Inicialmente, utilizar dados demonstrativos para construir e testar o layout.



IMPORTANTE: não afirmar que a loja está integrada à Nuvemshop até que a integração real seja implementada e testada.



RESULTADO ESPERADO



Entregar um e-commerce visualmente sofisticado, funcional, editável e preparado para evolução.



A Marcos Joias & Relógios deve ter aparência de uma marca profissional e consolidada.



O design deve valorizar os produtos, transmitir confiança e facilitar a conversão de visitantes em compradores.



A prioridade é uma experiência de compra premium, minimalista e comercial.
